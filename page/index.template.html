Then

Ensuite

  1. Open Control Panel → Plugins → Get more plugins → Open plugin library.
  2. A nikorion tab lists every plugin below: install the ones you want, then save and reload your wiki.
  3. Whenever a new version is published, that same screen offers it as an update.
  1. Ouvrez Panneau de configuration → Plugins → Obtenir d'autres plugins → Ouvrir la bibliothèque de plugins.
  2. Un onglet nikorion liste tous les plugins ci-dessous : installez ceux que vous voulez, puis enregistrez et rechargez votre wiki.
  3. À chaque nouvelle version publiée, ce même écran la propose en mise à jour.
